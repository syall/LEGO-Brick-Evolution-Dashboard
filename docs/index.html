Data Sources & Methodology

Rebrickable Database

Part, color, and set inventory data sourced from Rebrickable's public CSV downloads. Analysis covers 28,273 sets, 42,565 unique part designs (Rebrickable part IDs, a proxy for molds — includes printed variants and recolors), 275 Rebrickable color IDs, and 1.47M inventory records from 1949–2026.

LEGO Official History

Material history (ABS adoption in 1963, bio-polyethylene in 2018) from LEGO's official history articles and sustainability announcements.

Color Palette Research

Solid-color lifecycle data (228 solid colors, 75% discontinued) from The Data Drop's color analysis. Note: Rebrickable tracks 275 color IDs (including transparent, metallic, and chrome finishes); The Data Drop's 228 figure counts solid colors only. Part proliferation analysis from community inventory research.

Complexity Analysis

Set complexity trends from Mode Analytics' 67-year analysis and part introduction patterns from SafetyDave's BrickLink study. Large-set counts (1,000+ pieces) are used as a proxy for adult-oriented complexity; the LEGO 18+ age marking was introduced in 2020.
